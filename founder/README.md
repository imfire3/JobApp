# Founder pour JobTracker dans OpenCode

Installation locale : .opencode/skills/ (11 skills et scripts),
.opencode/commands/ (11 commandes). Sources : dossier local Founder Skill,
auteur Jake Schincariol, licence MIT dans .opencode/FOUNDER-LICENSE.
Adaptations : chemins locaux, sous-agents OpenCode general, contexte français.

1. Ouvrir /Users/macvincent/appjobs-v2 comme projet dans OpenCode.
2. Redémarrer la session si elle était déjà ouverte ; sélectionner Build pour
   permettre l’écriture des livrables.
3. Lancer /founder-board ; répondre aux questions sur les données manquantes.
4. Puis /founder-competitors et /founder-consumer --quick.
5. Continuer dans l’ordre de context.md, en examinant chaque résultat.

Les commandes chargent leur skill et founder/context.md. Pas de modèle imposé :
le modèle OpenCode déjà choisi est conservé. Recherche web et sous-agents
requièrent des outils disponibles dans la session. Ne jamais inventer leur exécution.
Python 3.8+ est nécessaire pour les quatre utilitaires, sans paquet supplémentaire.
Aucune analyse ni simulation n’a été lancée pendant l’installation.

Documentation : https://opencode.ai/docs/skills/ et https://opencode.ai/docs/commands/
